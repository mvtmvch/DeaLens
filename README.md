# DeaLens

Minimalny scaffold aplikacji do analizy ofert używanego sprzętu.

## Uruchomienie

Wymagane są Node.js 20.9 lub nowszy oraz npm.

```bash
npm install
npm run dev
```

Aplikacja będzie dostępna pod adresem [http://localhost:3000](http://localhost:3000).

## Weryfikacja

```bash
npm test
npm run lint
npm run build
```

Zakres MVP i bieżące decyzje znajdują się w katalogu `docs`.
